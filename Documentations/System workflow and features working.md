Working of System Features
1. Home Page
Displays information about skin treatment services.
Shows featured doctors, products, and navigation options.
Provides Login and Sign Up buttons.
2. Sign Up / Login
New users create an account.
Existing users enter email and password to log in.
3. Authentication
System verifies user credentials.
Identifies user role (Patient, Doctor, Admin, Rider).
Redirects user to the appropriate dashboard.
4. Patient Dashboard
Displays appointments, prescriptions, orders, rating and review, and notifications.
Provides access to all patient-related features.
5. Profile Setup
Patient enters personal and medical information.
Data is stored for future consultations.
6. Doctor List
Displays available doctors with specialization and consultation fees.
Patient selects a doctor for consultation.
7. Appointment Booking
Patient selects doctor, date, and time slot.
System confirms appointment availability and saves booking.
8. Payment Integration
Patient pays consultation or product charges online.
System records payment details securely.
9. Email Notification
Sends appointment confirmations, reminders, and order updates.
Notifies both patients and doctors.
10. Doctor Dashboard
Displays appointments, patient details, and prescriptions.
Allows doctors to manage consultations.
Show rating and review submitted by patients.
11. Prescription Generator
Doctor creates a digital prescription.
Prescription is stored and shared with the patient.
12. Rating and Review
Patient submits feedback and ratings after consultation.
Reviews help improve service quality.
13. E-Commerce Store
Displays skincare products available for purchase.
Patients can browse product categories.
14. Add to Cart
Selected products are added to the shopping cart.
User can update quantity or remove items.
15. Checkout
User confirms shipping details and payment.
Order is placed successfully.
16. Admin Dashboard
Manages patients, doctors, products, appointments, and orders.
Provides reports and system monitoring features.
17. Rider Assignment
Admin assigns a rider to a confirmed order.
Rider receives delivery details.
18. Rider Dashboard
Displays assigned deliveries and customer information.
Helps riders manage deliveries efficiently.
19. Delivery Status Update
Rider updates order status (Picked Up, In Transit, and Delivered).
Status changes are visible to the patient.
20. Order Notification
System sends notifications about order confirmation, dispatch, and delivery.
Keeps patients informed throughout the delivery process.
Complete Workflow
Home Page → Sign Up/Login → Authentication → Patient Dashboard → Profile Setup → Doctor List → Appointment Booking → Payment Integration → Email Notification → Doctor Dashboard → Prescription Generator → Rating & Review → E-Commerce Store → Add to Cart → Checkout → Admin Dashboard → Rider Assignment → Rider Dashboard → Delivery Status Update → Order Notification → Order Completed.
